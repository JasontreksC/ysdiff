# 연성대학교 배경 틀린그림찾기
## 주요 파일
- main.py: 메인 게임 로직 소스코드입니다. 파이게임을 활용합니다.
- quiz.py: 퀴즈 객체입니다. 왼쪽/오른쪽 이미지 쌍 및 챕터 번호, 정답 좌표등을 저장합니다.
- answers.csv: 정답 좌표들을 정리해놓는 csv 파일입니다. 한 행에 (챕터번호, X좌표, Y좌표)로 구성하고 csv모듈로 읽어와 사용합니다.
- images/: 퀴즈용 이미지들을 저장할 폴더입니다. 파일명 규칙은 ysu{챕터번호}_L.jpg, ysu{챕터번호}_R.jpg 입니다.
## 실행 방법
1. 깃 클론 후 해당 위치를 터미널을 엽니다. 가상환경을 사용한다면, 먼저 활성화합니다.
2. pygame 패키지를 설치합니다.
```bash
pip install pygame
```
3. main.py 파일을 실행합니다.
```bash
python main.py
```
